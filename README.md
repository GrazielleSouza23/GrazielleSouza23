## 🚀 Projetos em destaque

### 🌐 Gatos da Lagoa Taquaral

**Site institucional e painel administrativo desenvolvido voluntariamente para uma ONG de proteção animal.**

Aplicação web desenvolvida com **PHP, MySQL, HTML5, CSS3 e JavaScript**, com conteúdo dinâmico gerenciado por banco de dados e painel administrativo para gerenciamento do conteúdo.

#### ✨ Principais recursos

- 🔐 Autenticação administrativa
- 🔑 Armazenamento seguro de senhas com hash Argon2ID
- 🗄️ Operações CRUD
- 🛡️ PDO e Prepared Statements
- 📤 Upload de imagens com validação de tipo, tamanho e dimensões
- 📱 Interface responsiva
- 🎨 CSS Grid, Flexbox e Media Queries
- ⚡ Interações e animações com JavaScript
- 🗃️ Gerenciamento de eventos, galeria de imagens e histórias de sucesso

### 🎫 Sistema de Chamados e Suporte em Java

**Aplicação desktop desenvolvida em Java para gestão e rastreamento de chamados de suporte técnico.**

O sistema utiliza arquitetura **MVC** e foi desenvolvido com foco em organização, segurança e desempenho.

#### ✨ Principais recursos

- 🏗️ Arquitetura MVC
- 🎫 Gestão e rastreamento de tickets de suporte
- 👥 Fluxo de trabalho entre usuários finais e agentes técnicos
- 🔐 BCrypt para hashing seguro de senhas
- 🛡️ Criptografia AES-256 GCM para dados sensíveis
- 🗄️ Persistência de dados com MySQL
- ⚡ HikariCP para gerenciamento de pool de conexões
- 🔒 Boas práticas de segurança na interação com o banco de dados
